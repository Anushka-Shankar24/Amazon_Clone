# Amazon Clone

A frontend Amazon Clone website built using **HTML5 and CSS3**.

## Features

* Amazon-inspired navigation bar
* Search bar and navigation menu
* Hero banner section
* Product/category cards
* Promotional sections
* Responsive and clean user interface

## Technologies Used

* HTML5
* CSS3
* Font Awesome

## Project Structure

* `ProjectAmazon.html` — Main webpage
* `AmazonStyle.css` — Website styling
* Image files — Product, banner, and UI images

## Purpose

This project was created to practice and demonstrate frontend web development skills, including **HTML structure, CSS styling, layouts, and responsive UI design**.

## Future Improvements

* Add JavaScript functionality
* Add shopping cart
* Add product search
* Add product detail pages
* Improve mobile responsiveness
